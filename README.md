# Hey, I'm Emiliano 

I'm a web application pentester interested in how things work under the hood, especially when they don't work the way they were intended to.

Most of my work revolves around web applications, APIs, source code, and figuring out how seemingly small implementation details can turn into security issues.

I also enjoy building tools, putting together vulnerable environments, and sharing what I learn along the way.

### What I do
- Web application and API penetration testing
- Source code review and application security
- Security research and scripting
- Building labs and workshops for other people to learn from

### Community & Teaching

I enjoy giving talks, mentoring interns, and helping people get started with application security.

A lot of what I learn ends up in workshops, writeups, or small projects. If it saves someone else a few hours of troubleshooting, even better.
